# ProjectGuardian

**Estado: especificación arquitectónica en elaboración; implementación no iniciada.**

ProjectGuardian es una infraestructura independiente para custodiar objetivos, arquitecturas, contratos, propiedades, obligaciones, campañas, correspondencias entre especificación e implementación, auditorías, evidencias y certificaciones acotadas de proyectos de software e investigación.

La aplicación está diseñada para uso humano, monoagente o multiagente, sin conceder a los agentes autoridad para modificar sus propios criterios de aceptación. Los proyectos gestionados mantienen fuentes y constituciones separadas.

El índice de documentación, decisiones, campañas y responsabilidades físicas se publicará bajo `docs/` y `architecture/`. La existencia de esta documentación no supone código implementado, pruebas ejecutadas ni cualificación científica.
